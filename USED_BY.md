# Used by

Known uses of this repository by other people: tables that list its results, papers and deposits that cite it, and repositories that build on it. Each entry links to the public document. Promises and private correspondence are not listed. Last checked: 21 November 2026.

## Uses

- Henry Cohn's table of spherical codes (spherical-codes.org) credits 443 entries "Arhan Canli, 2026." (read 16 November 2026); see [quantavane-spherical-codes](https://github.com/arhancanli/quantavane-spherical-codes).
- Andries Brouwer's table of constant weight codes ([aeb.win.tue.nl/codes/Andw.html](https://aeb.win.tue.nl/codes/Andw.html)) lists 31 entries keyed "Can" (read 18 November 2026).
- The Lille catalogue of fast matrix multiplication algorithms lists ⟨9×10×11:640⟩ and ⟨9×11×11:708⟩ as "Canli 2026" (read 18 November 2026); see [quantavane-fmm-records](https://github.com/arhancanli/quantavane-fmm-records).
- The House of Graphs table of cages lists six girth-7 cage bounds with the reference [C26] (read 13 November 2026).
- Christopher Smolen's ca-tools table of covering arrays has merged 33 pull requests with these bounds; see [quantavane-covering-arrays](https://github.com/arhancanli/quantavane-covering-arrays).
- The Covering Repository lists the improved covering designs; see [quantavane-covering-records](https://github.com/arhancanli/quantavane-covering-records).
