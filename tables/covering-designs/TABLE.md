# Covering designs: living record table

**What a cell holds.** C(v, k, t) <= b and C(v, k, t, m) <= b: b blocks of size k on v points such that every m-subset meets some block in at least t points (m = t for C(v, k, t)). Fewer blocks is better.

**The table this follows.** The Covering Repository (https://coveringrepository.com), which continues Daniel Gordon's La Jolla Covering Repository. That table remains the reference for every cell; this one lists the cells where Quantavane holds the best value we know, with the previous best and its source, and takes better constructions from anyone (see [SUBMIT.md](SUBMIT.md)).

**Checker.** [CHECKER.md](CHECKER.md): two separately written exact routines in [checker.py](checker.py).

**Now.** 132 record rows covering 132 cells: 132 listed by the keeper.

Built from [data/records.csv](../../data/records.csv) by scripts/make_tables.py; the previous best is the value the table listed, or the best published value we found, when the record was set. Where no public Quantavane file holds the certificate yet, the column says so; for cells a keeper lists, the keeper's table holds the object.
