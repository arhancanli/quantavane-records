# Cages: living record table

**What a cell holds.** n(k, g) <= N: a k-regular graph of girth g on N vertices. Fewer vertices is better.

**The table this follows.** The House of Graphs cage table (https://houseofgraphs.org/meta-directory/cages), kept by Jan Goedgebeur, Jorik Jooken and Tibo Van den Eede. Since autumn 2026 it lists a first value for an empty cell only for graphs of at most 10,000 vertices. That table remains the reference for every cell; this one lists the cells where Quantavane holds the best value we know, with the previous best and its source, and takes better constructions from anyone (see [SUBMIT.md](SUBMIT.md)).

**Checker.** [CHECKER.md](CHECKER.md): two separately written exact routines in [checker.py](checker.py).

**Now.** 16 record rows covering 16 cells: 6 listed by the keeper, 10 sent to the keeper.

Built from [data/records.csv](../../data/records.csv) by scripts/make_tables.py; the previous best is the value the table listed, or the best published value we found, when the record was set. Where no public Quantavane file holds the certificate yet, the column says so; for cells a keeper lists, the keeper's table holds the object.
