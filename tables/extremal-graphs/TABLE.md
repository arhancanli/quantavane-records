# Extremal graphs without short cycles: living record table

**What a cell holds.** ex(n; t) >= m: a graph on n vertices with m edges and no cycle of length t or less. More edges is better.

**The table this follows.** The Combinatorics Wiki tables of extremal numbers ex(n; t) (http://combinatoricswiki.org/wiki/Ex(n;t)). That table remains the reference for every cell; this one lists the cells where Quantavane holds the best value we know, with the previous best and its source, and takes better constructions from anyone (see [SUBMIT.md](SUBMIT.md)).

**Checker.** [CHECKER.md](CHECKER.md): two separately written exact routines in [checker.py](checker.py).

**Now.** 24 record rows covering 24 cells: 24 verified, not yet sent.

Built from [data/records.csv](../../data/records.csv) by scripts/make_tables.py; the previous best is the value the table listed, or the best published value we found, when the record was set. Where no public Quantavane file holds the certificate yet, the column says so; for cells a keeper lists, the keeper's table holds the object.
