# Graphs and digraphs of given degree and diameter: living record table

**What a cell holds.** The largest known graphs or digraphs of maximum degree d and diameter k, in four tables: vertex-symmetric digraphs, Cayley graphs, bipartite graphs and arc-transitive graphs. A larger order is better. Submissions are open for vertex-symmetric digraphs given as Cayley or coset digraphs of PSL(2, q) or PGL(2, q) (times a cyclic group); the other three tables are listed but not yet open.

**The table this follows.** The Combinatorics Wiki degree-diameter tables (http://combinatoricswiki.org/wiki/The_Degree_Diameter_Problem_for_Vertex_Symmetric_Digraphs and its sister pages). That table remains the reference for every cell; this one lists the cells where Quantavane holds the best value we know, with the previous best and its source, and takes better constructions from anyone (see [SUBMIT.md](SUBMIT.md)).

**Checker.** [CHECKER.md](CHECKER.md): two separately written exact programs from a public Quantavane repository, named there.

**Now.** 57 record rows covering 57 cells: 44 sent to the keeper, 13 verified, not yet sent.

Built from [data/records.csv](../../data/records.csv) by scripts/make_tables.py; the previous best is the value the table listed, or the best published value we found, when the record was set. Where no public Quantavane file holds the certificate yet, the column says so; for cells a keeper lists, the keeper's table holds the object.
