# Constant weight codes: living record table

**What a cell holds.** A(n, d, w) >= M: M binary words of length n and weight w, any two at distance at least d. More words is better.

**The table this follows.** Andries Brouwer's tables of constant weight codes (https://aeb.win.tue.nl/codes/Andw.html). That table remains the reference for every cell; this one lists the cells where Quantavane holds the best value we know, with the previous best and its source, and takes better constructions from anyone (see [SUBMIT.md](SUBMIT.md)).

**Checker.** [CHECKER.md](CHECKER.md): two separately written exact routines in [checker.py](checker.py).

**Now.** 39 record rows covering 39 cells: 39 listed by the keeper.

Built from [data/records.csv](../../data/records.csv) by scripts/make_tables.py; the previous best is the value the table listed, or the best published value we found, when the record was set. Where no public Quantavane file holds the certificate yet, the column says so; for cells a keeper lists, the keeper's table holds the object.
