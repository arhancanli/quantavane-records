# Spherical codes: living record table

**What a cell holds.** N points on the unit sphere in R^d with largest pairwise cosine C. A smaller largest cosine (a larger minimum angle) is better.

**The table this follows.** Henry Cohn's table of spherical codes (https://spherical-codes.org). That table remains the reference for every cell; this one lists the cells where Quantavane holds the best value we know, with the previous best and its source, and takes better constructions from anyone (see [SUBMIT.md](SUBMIT.md)).

**Checker.** [CHECKER.md](CHECKER.md): two separately written exact routines in [checker.py](checker.py).

**Now.** 443 record rows covering 443 cells: 443 listed by the keeper.

Built from [data/records.csv](../../data/records.csv) by scripts/make_tables.py; the previous best is the value the table listed, or the best published value we found, when the record was set. Where no public Quantavane file holds the certificate yet, the column says so; for cells a keeper lists, the keeper's table holds the object.
